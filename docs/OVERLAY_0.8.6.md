# Overlay — installation and troubleshooting

Import the complete profile after manually deleting the previous one. The bridge locates its bundled Python/Node and host directly inside the profile and starts them automatically on injection. No setup script or host.ini is needed. Chromium is bundled; Microsoft Edge is not required.

F10 toggles the panel; hold both triggers and grips for two seconds to open it with compatible controller actions, then release to rearm. Right controller operates the panel. The UEVR External overlay startup option applies next session.

If the panel does not appear, inspect the startup status in UEVR and ExternalOverlay/host/logs. Confirm the complete archive was imported, bundled files are present and the bundled Chromium runtime is complete. Do not launch a second host manually or restore paths from an older installation. Close the game normally before repairing files.

Resolution requires the exact Nightly 01143 and an immersive OpenXR session with fresh stereo projection views. UEVR's original controls remain available. Selection, submitted dimensions and persistence are distinct. Review/discard conflicts rather than retrying uncertain mutations.

For recovery, close the game and restore the complete recovery profile. Do not run source-workspace rollback tools on a user installation.
